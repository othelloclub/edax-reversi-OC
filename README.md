# edax-reversi-OC

Othelloclub's modified Edax, a GPLv3 Othello engine.

This is the engine source used in the [FlipSight](https://othelloclub.com/en/flipsight/) app up to version 2.0.4 and in the former FlipSight web analysis.
FlipSight now uses its own engine, FlipMind, so this repository is kept as a read-only archive.

This repository provides the corresponding source for the GPLv3-licensed binaries distributed by Othelloclub.

- Upstream: [Edax](https://github.com/abulmo/edax-reversi) by Richard Delorme and [edax-reversi-AVX](https://github.com/okuhara/edax-reversi-AVX) by Toshihiko Okuhara.
