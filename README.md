# edax-reversi-OC

Othelloclub's modified Edax, a GPLv3 Othello engine.

This repository provides the corresponding source for the GPLv3-licensed binaries previously distributed by Othelloclub.
It is no longer updated and is kept as a read-only archive.

- Upstream: [Edax](https://github.com/abulmo/edax-reversi) by Richard Delorme and [edax-reversi-AVX](https://github.com/okuhara/edax-reversi-AVX) by Toshihiko Okuhara.
